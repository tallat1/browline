# Security

Browline runs a local activity socket, handles a URL scheme and can answer Claude Code permission prompts, so security reports matter.

Please report vulnerabilities privately through [GitHub security advisories](https://github.com/tallat1/browline/security/advisories/new) instead of a public issue. Include the macOS version, the Browline version and steps to reproduce. You can expect a first answer within a week.

Only the latest release receives fixes.
